# 📋 Sistema de Gerenciamento de Tarefas

## 🎯 Objetivo do projeto

O Sistema de Gerenciamento de Tarefas é uma aplicação desenvolvida em Python com o objetivo de auxiliar no cadastro e na organização de tarefas.

A aplicação permite cadastrar novas tarefas, visualizar tarefas cadastradas, marcar tarefas como concluídas e excluir tarefas. As informações são armazenadas em um arquivo de texto, permitindo que os dados permaneçam salvos mesmo após o encerramento do programa.

O projeto foi desenvolvido com finalidade acadêmica, buscando aplicar na prática os conceitos estudados na disciplina de Programação de Computadores.

## 💻 Tecnologias utilizadas

- Python 3
- Estruturas condicionais (`if`, `elif` e `else`)
- Estruturas de repetição (`for` e `while`)
- Funções
- Listas
- Dicionários
- Manipulação de strings
- Tratamento de exceções (`try` e `except`)
- Manipulação de arquivos
- Arquivos de texto (`.txt`)

## ⚙️ Funcionalidades                                                                                                                                                

- Cadastro de tarefas com título e descrição
- Listagem das tarefas cadastradas
- Conclusão de tarefas
- Exclusão de tarefas
- Salvamento das tarefas no arquivo `tarefas.txt`
- Recuperação das tarefas ao iniciar o programa novamente
